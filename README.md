Matlab code to analyze intracellular recordings of the Drosophila NMJ. Inputs required .mat files of from Chart 5 software. 
mEJP_analysis.m takes a batch of recordings and returns mini frequency, amplitude and average membrane potential. 
mEJP_analysis_individual_amps.m returns the individual mini amplitudes of a recording.
HFMR_analysis.m analyzes High frequency mini release recordings and graphs the mini frequency over time. (for info about HFMR see:
